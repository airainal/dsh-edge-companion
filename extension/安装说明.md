# 安装 / 更新 DSH Edge Bridge 扩展（约 30 秒）

要加载的文件夹（**选这个目录**）：

```
C:\Users\a\Documents\deepseek-harness\default-workspace\dsh-edge-companion\extension
```

## 第 1 步：打开开发人员模式

1. Edge 地址栏输入 `edge://extensions` 回车
2. 打开左侧栏底部的 **「开发人员模式」**（Developer mode）开关

## 第 2 步：加载解压缩的扩展

1. 点页面上方出现的 **「加载解压缩的扩展」**（Load unpacked）
2. 选择上面的 `extension` 文件夹 → **选择文件夹**

装好后会出现一张 **DSH Edge Bridge 1.2.0** 的卡片（图标是蓝色大肥鱼）。

> **已经装过旧版？** 不用卸载：在 `edge://extensions` 里点该卡片的 **刷新 ↻** 即可升级到
> 1.2.0（新图标、浅色 UI、顶部会话选择/新建、底部模型切换、圆角浮层下拉与滑动切换动画、
> 与 DSH 双向同步）。扩展 ID 不变，设置保留。

## 第 3 步：启动桥接（必须）

扩展只是「手」，不会自己拉起服务；**没连上最常见的原因就是桥接没在跑**。

**方式 A（推荐，一键启动，不是开机自启）**

先双击一次（只需一次，无需管理员，无黑窗口）：

```
C:\Users\a\Documents\deepseek-harness\default-workspace\dsh-edge-companion\scripts\install-protocol.vbs
```

之后侧边栏断线时会显示 **「启动桥接」** 和 **「启动并打开 DSH」** 按钮，点一下就会在后台拉起桥接
（无窗口），几秒内自动变绿。**首次点击时 Edge 会弹窗询问「要打开 DSH Edge Bridge 吗？」——点「打开」
（可勾选「始终允许」）**。这一步不是开机自启：不点就不跑。

**方式 B（手动）**

双击：

```
C:\Users\a\Documents\deepseek-harness\default-workspace\dsh-edge-companion\bridge\start-bridge.cmd
```

保持那个窗口开着。想开机常驻（可选）：跑一次
`scripts\install-autostart.ps1`（在「启动」文件夹建快捷方式；加 `-Remove` 撤销）。

## 第 4 步：验证

1. 点 Edge 工具栏的扩展图标。角标状态：
   - **● 绿色** = 已连上桥接
   - **○ 灰色** = 桥接没起（扩展每 1–30 秒自动重连，起好后自动变绿）
2. 侧边栏顶部会出现**会话下拉框 + ＋新建**，底部有**模型下拉框**；输入框可用即可。

命令行验证（不需要点界面）：

```bat
cd C:\Users\a\Documents\deepseek-harness\default-workspace\dsh-edge-companion
bin\edge.cmd status
```

看到 `"connected": true` 就通了。

## 换一台电脑

整个 `dsh-edge-companion` 文件夹可以原样拷到新机器任意目录。新机器需要有 Edge 114+ 和**已安装并登录**的
DeepSeek Harness。装好后到新机器上重做这三件事（都是一次性的）：

1. 加载解压缩这个 `extension` 文件夹
2. 双击 `scripts\install-protocol.vbs`（可选，用来一键启动桥接；无黑窗口）
3. 运行时点侧边栏「启动桥接」，或双击 `bridge\start-bridge.cmd`

自检：`powershell -ExecutionPolicy Bypass -File scripts\verify-install.ps1`（全 PASS 即可）。
DSH 装在非标准位置也能自动发现（环境变量 / 注册表卸载信息 / 自带 node 反推）；实在找不到就在
`bridge\engines.json` 里填 `dsh.exe`，或设环境变量 `DSHEDGE_DSH_EXE`。

## 怎么用

- **发指令**：侧边栏输入「打开 bilibili.com 看看热门」→ 自动唤醒无头 DSH 执行，思考/工具/回复实时出现。
- **选会话**：顶部下拉框列出该工作目录下的真实 DSH 会话；选中即接力，`＋` 新建。
  这些会话在 DSH 桌面版里也看得到、能接着聊，两边的消息会互相同步。
- **换模型**：底部「模型」下拉框（DeepSeek-V4.1-Flash / DeepSeek-V4-Pro），下条指令生效。

## 常见问题

- **页面顶部出现「扩展正在调试此浏览器」**：正常现象。Chromium 对 `chrome.debugger` 的固定提示，
  表示 DSH 正在通过 CDP 操作该标签页；关掉标签页或 detached 后消失。
- **侧边栏显示「桥接未连接」**：点「启动桥接」按钮（需先双击一次 `scripts\install-protocol.vbs`），
  或双击 `bridge\start-bridge-hidden.vbs` / `bridge\start-bridge.cmd`；若用了自定义端口，点侧边栏 ⚙ 改地址。
- **另一个浏览器抢不到连接**：一个桥接同一时间只服务一个浏览器安装；关掉当前那个的扩展/浏览器再试。
- **改了扩展代码**：到 `edge://extensions` 点该卡片的刷新图标 ↻。
- **升级/重装**：直接覆盖 `extension` 目录内容后点刷新即可；`manifest.json` 里的 `key` 固定了
  扩展 ID（`kioclakapkblemfnlgcfbciedfhkpmhc`），不要删改。
- **不想用了**：`edge://extensions` 里移除扩展即可；扩展没有外部数据残留，桥接目录可整包删除。
